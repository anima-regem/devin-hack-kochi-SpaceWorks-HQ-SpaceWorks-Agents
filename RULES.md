# Project rules and template provenance

This project's documentation structure is adapted from the
[DevDay Kochi hackathon template](https://github.com/anima-regem/devday-kochi-hackathon-template).
Its [event rules](https://github.com/anima-regem/devday-kochi-hackathon-template/blob/main/RULES.md)
describe an open-theme event on 10–11 October 2026. Those historical dates and
eligibility statements are not claims about this project's development.

## Current working rules

- The user authorized implementation on 24 October 2026, with parallel work,
  phase commits, passing tests and a priority on staff operations.
- Operate inside the Agents folder. Do not inspect or modify sibling applications.
- Preserve app authorization, tenant boundaries and existing domain invariants.
- Validate inputs and verify results. Record real checks and limitations.
- Keep credentials and private records out of source and logs.
- Use small coherent milestones; commit each phase only after its checks pass.
- Document meaningful changes and actual AI assistance. No invented demos,
  provider calls, test results or historical timestamps.

See [AGENTS.md](AGENTS.md) for implementation conventions.
